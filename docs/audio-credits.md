# 声音与授权说明

## 背景音乐

- 曲名：**Parcel Street Loop**（原创）。
- 来源：游戏运行时由 `src/ui/music.ts` 用 Web Audio 现场合成；没有外部音频文件、没有采样包、没有付费素材。
- 授权：以 **CC0 1.0** 释出，可商用、可修改、无需署名。
- 结构：66 BPM，64 个八分音符 = 29.09 秒；4 小节和弦（Cmaj7 → Am7 → Fmaj7 → Gsus4）重复两遍，第 4 小节接回第 1 小节，循环无接缝。
- 体积：**0 KB**（不增加初始包体）。

## 音效

- 全部为 Web Audio 合成的原创音效，同样以 **CC0 1.0** 释出。
- 统一通过一个 master bus：6.5 kHz 低通 + 压缩器（threshold −20 dB、ratio 4:1），去掉刺耳高频并拉平响度差。
- 音乐走独立的 warm low-pass（2.4 kHz）和较低的音量，音效响起时自动短暂让位（ducking）。

## 播放规则

- **第一次用户点击/按键之后**才创建 AudioContext；页面加载不自动播放（iOS 要求）。
- 跟随 CrazyGames SDK 的 `game.settings.muteAudio`：`addSettingsChangeListener` 变化时暂停/恢复。
- 跟随游戏内静音按钮（`state.muted`）和宿主静音：立即把 master bus 音量淡到 0（约 35 ms），已经排好的音符也马上停；再点一次恢复。设置写进存档，刷新后保留。
- 广告播放期间静音，广告结束恢复。
- 切后台时 AudioContext 挂起并停止排音符；回到页面后不自动恢复，要在下一次点击、触摸或按键里继续，不补播后台期间的音符。iOS 的 `interrupted` 状态（来电、锁屏）也走同一条恢复路径。

## 验证

- `npx vitest run tests/audio.test.ts`：检查循环长度、低通上限、调度器在静音时不排音符、停止后不再排音符；同时检查 8 种物品声音和 10 种操作声音都能发声，以及 master bus、ducking 和静音时 master 音量目标为 0 / 取消静音后恢复。
- `npx vitest run tests/no-emoji.test.ts`：检查 UI 文案里的 emoji 都有对应图标。

## 听感说明（M3 董事会试听）

全部声音都是“短事件音”，没有环境循环、没有角色配音、没有外部音频文件。听感目标是安静、温暖、不抢注意力：音乐只有一条 29 秒的循环，操作音都短，连续点击不会叠成噪音。

| 项目 | 听感 |
| --- | --- |
| 背景音乐 | 66 BPM，29.09 秒无缝循环；Cmaj7 → Am7 → Fmaj7 → Gsus4。三角波铺底、正弦波旋律，2.4 kHz 低通，整体像安静的小镇午后。 |
| 物品声音 | 8 种：沙沙、咚、晃荡、咔嗒、哐当、叮当、叮、吱。每种物品固定一种，玩家可以靠声音辨认内容。 |
| 拆包 | 划胶带是高频撕裂声；拖动时有细小摩擦声；打开箱盖是低频纸板“噗”。 |
| 揭晓 | 普通单音、稀有三级上行、史诗四音叠和弦、隐藏七音琶音，长度从 0.4 秒到 2 秒。 |
| 反馈 | 按钮是 60 毫秒的轻点；金币/碎片是两枚方波硬币；称重是两声木琴轻点。 |
| 总线 | 音效统一走 6.5 kHz 低通 + 压缩器（threshold −20 dB、ratio 4:1）；音乐走独立 2.4 kHz 低通，音量 13%，音效响起时短暂让位（ducking）。 |

试听页：预览构建打开 `audio.html`，可以直接播放音乐和全部 18 个音效；`?lang=zh` 或 `?lang=en` 切换说明语言。正式构建不会展示这个页面。

## 开关位置

- **游戏内**：小站页右上角、金币栏右侧、语言按钮左侧的扬声器图标。点一下静音，再点一下恢复；设置写进存档，刷新后保留。
- **CrazyGames**：宿主设置里的 `game.settings.muteAudio` 优先于游戏内按钮；宿主静音时游戏内按钮变灰。
- **Discord / 网页**：使用同一个游戏内扬声器按钮。
- **自动播放**：页面加载时不出声；第一次点击或按键后才创建 AudioContext 并开始音乐（iOS 要求）。切后台时挂起，回到页面后在下一次点击、触摸或按键里恢复；广告期间静音。游戏内或宿主静音会立即静音，不会响完已经排好的音符。
